# **App Name**: CampusFind

## Core Features:

- User Authentication: Secure user login and signup using Firebase Authentication.
- Item Reporting: Users can report lost or found items with images.
- AI-Powered Item Description: Generative AI is used as a tool to suggest descriptions for the items being reported based on the uploaded images. This description is only a suggestion and the user will have the option to ignore it.
- Search and Filter: Users can search and filter items by keywords, categories, and location.
- Claim Process: Implement a claim process where users can claim found items.
- Admin Approval: Admin approval workflow for claims to ensure legitimate requests.
- Notifications: Real-time notifications via Firebase Cloud Messaging for claim updates and admin approvals.
- Admin Dashboard: Admin dashboard with statistics on lost/found items and claims.

## Style Guidelines:

- Primary color: Soft blue (#A0D2EB) to convey trust and calmness.
- Background color: Very light blue (#F0F8FF), almost white, for a clean look.
- Accent color: Pale violet (#D0BFFF) for interactive elements, providing a modern feel.
- Body and headline font: 'PT Sans' (sans-serif) combines a modern look and a little warmth or personality; suitable for headlines or body text
- Simple and clear icons to represent item categories and actions.
- Clean and responsive layout optimized for both desktop and mobile devices using Next.js and Tailwind CSS.
- Subtle animations for transitions and feedback on user interactions.
